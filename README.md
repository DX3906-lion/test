# API 编排平台（Java8 + MySQL）

## 1) 需求优化（V1）

### 1.1 功能范围
- HAR 导入：支持一次导入多个接口，自动提取 method/url/header/body。
- 调试能力：支持单接口调试、断点调试、变量查看。
- 内容过滤：支持按域名、路径、方法、状态码过滤导入接口。
- 编排流程：支持拖拽排序、串并行、条件控制器（if/else）。
- 变量传递：支持响应提取（JSONPath）并注入后续请求。
- 参数化：环境变量、数据集驱动（CSV/JSON）。
- 断言：状态码断言、JSON 字段断言、正则断言。
- AI 建议：对流程顺序、断言覆盖、变量命名给出建议；支持“一键采纳”。

### 1.2 非功能需求
- 性能：1000 条接口定义下，列表查询 < 2s。
- 可用性：关键操作（导入、保存编排、执行）可回溯。
- 安全：敏感字段（token/password）脱敏保存。
- 扩展性：执行引擎、AI 模块可独立替换。

## 2) 技术架构（V1）

- 后端：Spring Boot 2.7（Java8）
- 存储：MySQL 8，JPA 持久化
- 核心模块：
  - har-parser：HAR 解析与过滤
  - flow-designer：流程 DSL 存储（JSON）
  - runner-engine：执行、变量上下文、断言
  - ai-advisor：建议生成与采纳
  - case-manager：用例 CRUD
- 数据模型：
  - `api_case`: 用例主表（HAR 原文 + 流程定义）
  - 后续可拆分 `api_step`、`api_assertion`、`api_variable`

## 3) 当前已编码内容

- 已提供 AI 建议服务原型接口（当前为规则模拟）。
